
# Maven Market Sales dashboard

## Project Overview
This is an interactive Power BI dashboard built using the Maven Market dataset. The dashboard provides insights into sales performance, revenue, profit, transactions, returns and product performance across different regions. It was developed to strengthen my skills in Power BI, DAX, data modeling and dashboard design.

---

## Objectives 
- Analyze overall sales performance.
- Track revenue, profit, and orders.
- Monitor product performance and return rate.
- Compare sales across different countries.
- Understand customer purchasing behavior.
- Create an interactive dashboard for business insights.

## Key Insights
- Business performance can be monitored using revenue, profit, transactions, and return rate.
- Weekly revenue trends help identify sales patterns over time.
- Product brand analysis highlights the highest-performing brands based on transactions and profit.
- Geographic analysis allows comparison of performance across different countries.
- KPI tracking helps compare current performance against business targets.
